# Focused code-diff cleanup

Inspect the requested diff and nearby conventions. Remove only redundant comments, unnecessary scaffolding, or similar noise you can justify. Preserve behavior, useful validation, technical caveats, identifiers, error strings, and unrelated changes. Defensive code is not redundant merely because it looks generated. Run checks appropriate to meaningful edits. A cleanup request does not authorize publication. For prose within the diff, use Writing when the text serves other readers; do not compress it into session style.
