# Focused code-diff cleanup

Inspect the requested diff and nearby conventions. Remove only redundant comments, unnecessary scaffolding, or similar noise you can justify. Preserve behavior, useful validation, technical caveats, identifiers, error strings, and unrelated changes. Defensive code is not redundant merely because it looks generated. Comments that narrate the session ("per Codex review", "fixed in round 3", changelog notes) are noise; git history holds that. Keep comments that explain why code is the way it is, and TODOs that name a known gap. Run checks appropriate to meaningful edits. A cleanup request does not authorize publication. For prose within the diff, use Writing when the text serves other readers; do not compress it into session style.
